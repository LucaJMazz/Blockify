Blockify

Convert any image into minecraft blocks

Select scale

Scale: 50

The higher the scale, the more detailed the image


How to Use

Upload image

Upload any image in a .png, .jpg, .gif, .bmp, or .wbmp

File sizes must not be more than 20mb.

Any images uploaded are not saved to any server or database, it is polled directtly from the open source api and returned to the output box.

Output image

Download the converted image as a .png file onto yout computer by clicking the download button next to the result image.

View the full image in a new tab by clicking the view button next to the result image.

Clear the output image by clicking the clear button next to the result image.
