About

What is Blockify?

Blockify is a web application that transforms any image into a version built entirely from Minecraft blocks. Every pixel is analyzed and matched to the closest available Minecraft block texture, producing artwork that resembles something you could recreate in-game.

The project was built using Java with Spring Boot for the backend and HTML, CSS, and JavaScript for the frontend. Image processing is performed server-side using a custom color matching algorithm that compares each pixel against a palette of Minecraft block textures before generating the final image.

All uploaded images are processed only for the duration of the conversion. Files are not permanently stored on the server, and the generated image is returned directly to your browser.

Blockify is open source and continuously improving with new blocks, better color matching, and additional customization options planned for future updates.

API

REST API

Blockify also provides a simple REST API, allowing developers to convert images into Minecraft block art programmatically from their own applications.

Endpoint

POST /api/image/upload

Request

Send a multipart/form-data request containing:

  • image – The image file (.png, .jpg, .gif, .bmp, or .wbmp).
  • scale – An integer between 1 and 100 that controls the output resolution.

Response

On success, the API returns the converted image as a PNG file. If an unsupported file type or invalid request is submitted, an appropriate HTTP error code and message are returned.

Example

curl -X POST http://localhost:8080/api/image/upload \

				  -F "image=@myImage.png" \

				  -F "scale=50" \

				  --output blockified.png

The API is intended for personal projects, automation, and integration into Minecraft-related tools.
